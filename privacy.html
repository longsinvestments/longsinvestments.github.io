Privacy policy

Last updated: November 6, 2026

Channel Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channels. It has no other users.

What it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload videos, set their thumbnails and add caption files on the owner's channels. It does not read, collect or store any data about viewers or any other person.

What it stores

The only thing kept is the owner's own access token, stored as an encrypted secret in the owner's private GitHub repository so uploads can run on a schedule. It is never shared, sold or sent anywhere other than Google's APIs.

Google API services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The YouTube API Services are used under the YouTube Terms of Service; see also the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Questions: open an issue at github.com/longsinvestments.
